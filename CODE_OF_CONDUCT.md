# Code of Conduct

The project community is committed to a welcoming, respectful, and
constructive environment for everyone.

Expected behavior includes:

- using inclusive language and respecting different viewpoints;
- giving and receiving technical feedback with care;
- focusing criticism on ideas, code, and behavior rather than people; and
- protecting private information, credentials, and user data.

Unacceptable behavior includes harassment, discrimination, threats, personal
attacks, deliberate exposure of private information, and disruptive conduct in
project spaces.

Report a concern privately to the project maintainers through the repository's
hosting contact or security channel. Do not include secrets or raw user data.
Maintainers will review reports in good faith, protect the reporter's privacy
where possible, and may remove content or restrict participation when needed.

This code of conduct applies to project spaces and to conduct that materially
affects the safety of the project community.
